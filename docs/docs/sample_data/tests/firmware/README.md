# Auralynx Firmware

## Purpose

This folder contains the embedded firmware for the proposed Auralynx wearable device.

## Planned Functions

* Read motion sensor measurements.
* Process incoming sensor data.
* Evaluate configured safety-event detection rules.
* Communicate relevant event information to a compatible smartphone.

## Proposed Hardware

* ESP32 microcontroller.
* MPU6050 accelerometer and gyroscope, subject to final component selection.

## Development Environment

The firmware is planned to be developed using the Arduino IDE or a compatible ESP32 development environment.

## Setup

Detailed installation instructions, required libraries, pin connections, and firmware upload steps will be added after the hardware configuration is finalized.

## Status

Firmware implementation is pending. This document describes the planned development scope; it does not indicate that the firmware is operational.
