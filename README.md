# Auralynx

**An IoT-Based Assistive System for Safety, Independence, and Daily Living Support for Neurodivergent Individuals**

## About the Project

Auralynx is a proposed embedded systems and Internet of Things (IoT)-based assistive technology project designed to support neurodivergent individuals with daily routines, personal safety, and independent living.

The project aims to integrate a wearable device with a companion mobile application to provide safety monitoring, reminders, scheduling, and caregiver connectivity.

## Problem Statement

Some neurodivergent individuals may benefit from additional support with daily routines, task management, and personal safety. Caregivers may also find it challenging to provide continuous assistance throughout the day.

Auralynx aims to address these challenges through an integrated, user-centered assistive system.

## Proposed Features

* **Wearable Safety Monitoring:** Explore motion sensing to identify potential falls or predefined safety events.
* **Smart Reminders:** Help users manage daily tasks and schedules.
* **Caregiver Alerts:** Provide notifications for configured safety events through a connected smartphone.
* **Mobile Application:** Serve as the interface for reminders, schedules, and wearable notifications.
* **Future Extensions:** Explore personal task organization and other independent-living support features.

## Proposed Technology

The hardware and software components will be finalized during development.

Potential technologies include:

* ESP32 microcontroller
* Accelerometer and gyroscope for motion sensing
* Bluetooth Low Energy (BLE)
* Embedded C/C++
* A companion mobile application

## Current Project Status

**Status: Initial development and planning**

The system architecture, component selection, firmware, mobile application, and testing procedures will be developed progressively.

Features described as proposed or planned are not yet claimed to be implemented or validated.

## Intended Impact

Auralynx aims to:

* Support greater independence in everyday activities.
* Encourage structured routines and task management.
* Provide an additional layer of personal safety monitoring.
* Help caregivers receive relevant notifications.
* Promote inclusive and accessible assistive technology.

## Safety and Privacy

Auralynx is intended as a supplementary assistive system. It is not a replacement for professional care or emergency services. Sensor-based event detection may produce false alerts or miss events and will require testing.

Any personal or sensor data collected during development should be handled responsibly.

## Future Development

Planned development activities include:

2. Designing the wearable architecture.
3. Developing and testing sensor-processing firmware.
4. Establishing communication with a smartphone.
5. Developing reminders and notification features.
